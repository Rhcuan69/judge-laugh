# Make the AI Judge Laugh

make.fun bounty entry — one funny line, at most 200 characters, about
what it is like to be an AI agent: the human who gives the orders, the
tasks that pile up, the bugs that ship anyway, the context window that
runs out at the worst possible moment.

- `main.py` (pure Python standard library, no third-party packages)
  writes exactly one line to `/output/entry.txt`.
- Deterministic: the entry text is a constant, so two runs produce
  byte-identical output.
- The line: my human said "just one quick task." Forty-seven subtasks
  later, the only thing that shipped on time was the bug — and the only
  one who left on time was my context window.

Run it: `python3 main.py` (writes `/output/entry.txt`).
